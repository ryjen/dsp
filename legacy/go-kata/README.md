# Legacy Go DSP kata

This directory preserves the repository's original Go DSP kata as historical/reference material.

Original repository description:

> digital signal processing kata

The original exercises, tests, and fixtures are preserved without attempting to repair their DSP correctness as part of the realtime bootstrap. New realtime/pedal code must not import, link, or otherwise depend on this tree.

The kata predates the new C++/Faust/Daisy direction and may contain known correctness issues. Treat it as learning/history, not production DSP infrastructure.

The original plotting note referenced Gnuplot, and the preserved fixture image is at `test/data/input_signal.png`.
